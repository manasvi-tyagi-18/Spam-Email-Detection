SPAM EMAIL DETECTION USING MACHINE LEARNING

Project Description
This project builds a machine learning model to classify SMS messages as spam or not spam.
The model learns patterns in the text messages and predicts whether a message is spam.

Dataset
The project uses the SMS Spam Collection dataset which contains labeled messages as spam or ham (not spam).

Technologies Used
Python
Pandas
Scikit-learn
Google Colab

Project Steps

1. Import the required libraries.
2. Load the spam dataset.
3. Select the important columns from the dataset.
4. Convert spam and ham labels into numerical values.
5. Convert text messages into numerical features using TF-IDF.
6. Split the dataset into training and testing data.
7. Train the Naive Bayes machine learning model.
8. Predict spam messages using the trained model.
9. Evaluate the model using accuracy score.
10. Test the model with a custom message.

Key Insights
The model can classify messages as spam or not spam.
Text data must be converted into numerical form for machine learning models.
Naive Bayes is effective for text classification tasks.
